# ICEHOME 任务目标书

> 配套文档：[项目计划书](./项目计划书.md) · 编写日期：2026-11-15
>
> 用途：把「做一个家庭面板」拆成可验收的任务单元。每条任务都写明**交付物**与**判定方式**，判定方式优先是可执行的命令或测试用例，而不是主观描述。

---

## 一、总目标

在空目录 `ICEHOME/` 内交付一个可运行、可测试、可扩展的家庭设备控制面板：

- 后端：Node + Express，JSON 持久化，cron 调度，HTTP 设备适配器，AI 指令解析，OpenAI 兼容端点。
- 前端：React + Tailwind，黑白简约左右布局，桌面与手机自适应，全 SVG 图标。
- 质量：单元 / 集成 / E2E 三层测试全绿，文档齐备。

## 三、验收口径（可复制执行）

```powershell
cd C:\Users\User\Desktop\ICEHOME
npm test                 # 单元 92 + 集成 106 = 198
npm run build            # 产出 dist
npx playwright test      # E2E：18 passed / 18 skipped
npm run test:desktop     # Electron E2E：2 passed（打包冒烟默认跳过）
npm run desktop:dist:dir # 当前平台未压缩目录
npm start                # http://127.0.0.1:8787
npm run start:api        # 只提供 API（前后端分离）
npm run start:gateway    # 网关示例：http://127.0.0.1:8790
```

浏览器验收清单：

1. 首屏左右布局：左 300px 侧栏，右内容区；侧栏含分类卡片与 10 项控制台导航。
2. 点击「客厅」分类，主区只剩客厅设备；点击「全部设备」恢复。
3. 点设备卡打开右侧抽屉，调亮度滑杆后设备卡数值变化。
4. 新建分类「书房」，侧栏立即出现该卡片。
5. 新建任务「夜间关灯 每天 22:30」，任务卡显示下次执行时间。
6. 签发令牌，密钥只出现一次，格式 `sk-ice-…`；刷新后仅显示掩码。
7. 配对页生成二维码并批准，设备出现在对应分类。
8. AI 控制台输入「把客厅主灯亮度调到 40」，回显已执行且设备状态为 40%。
9. 手机宽度 390px：侧栏收起，汉堡菜单打开抽屉式导航。
10. 全页面无 emoji，图标均为 SVG。
11. 设置页「存储与缓存」显示当前驱动、地址、延迟与缓存命中；开启缓存后重复刷新 `/api/state` 命中率增长，写入后回落。
12. 系统页「数据模式」随 `STORAGE_DRIVER` / `SERVE_STATIC` 变化，不再写死为本地 JSON。
13. 只启动 API（`SERVE_STATIC=false`）时 `/api/health` 正常、`/` 不返回面板；网关 8790 可正常打开面板并代理接口。
14. 账户页新增成员并手动勾选设备，列表显示角色/授权/最近登录；管理员隐藏设备选择。
15. 平面图页画房间、拖动标记；框选客厅 4 台设备后选成员并「追加」，提示授权成功；成员侧栏只显示授权设备。
16. 二维码巡检页生成配置二维码，下载 JSON 包含 settings/分类/设备 adapter/任务/插件/平面图，不含账户与令牌。
17. 选择设备查看标签二维码；点「记录这台设备」后巡检表格新增一行；粘贴标签内容提交扫码巡检也新增记录。
18. Wi-Fi 区生成标准 Wi-Fi 二维码；扫描 `192.168.x.0/24` 后列出 IP/端口/延迟，「加入待配对」跳转配对页。
19. 成员进入二维码巡检页只能看到授权设备标签，不显示配置、Wi-Fi 与网段扫描卡片。
20. 双击 Electron 桌面端，启动器显示本地/远程两张模式卡、平台与 CPU 架构、版本、Electron 版本。
21. 本地模式默认 8788，端口被占用自动顺延；启动后自动打开面板，启动器可复制本机与局域网地址。
22. 远程模式填根地址，测试连接显示延迟与版本；保存为常用服务器；勾选自签名后能连家用 HTTPS。
23. 启动器关闭后可从托盘/菜单重新打开；本地服务可重启；同一 `data` 目录第二个进程被锁拒绝。

## 四、完成定义（Definition of Done）

- 功能：上述 T01–T55 全部为「完成」，无占位实现、无 TODO 路由。
- 测试：`npm test` 与 `npx playwright test` 均退出码 0，无 skip 的主流程用例。
- 构建：`npm run build` 无警告级错误，dist 可被 `npm start` 托管。
- 文档：计划书、任务目标、README 三者互链，命令可直接执行。
- 视觉：桌面与手机截图人工核对通过（`test-results/shots/`）。
- 约束：黑白配色、左右布局、SVG 图标、OpenAI 风格令牌、扫码导入、插件均可在界面中验证。

| 语义解析覆盖 | 复杂多条件句会落到候选提示，未接大模型 |

| 配置恢复 | 配置二维码是 10 分钟有效的只读下载链接，扫码下载 JSON，暂不支持在面板内一键恢复 |
| 巡检 | 即时巡检记录（设备/状态/备注/巡检人），无巡检计划、报告导出、异常工单；摄像头识别依赖 `BarcodeDetector` |

| 平面图 | 单层 SVG 画布，可建多张；不支持导入户型图或自动识别墙体 |
