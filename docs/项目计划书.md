# ICEHOME 项目计划书

> 版本：v1.4 · 编写日期：2026-11-15 · 项目根目录：`ICEHOME/`
>
> 一句话定位：**参考 Home Assistant 的能力模型，面向家庭场景的黑白简约设备控制面板** —— 能把家里大多数设备接进来，也能为没有现成集成的设备手写 HTTP 接口。

---

## 1. 背景与参考对象

Home Assistant（下称 HA）证明了「统一设备模型 + 可插拔集成 + 自动化」这套结构在家庭场景是成立的，但它的默认界面偏工程化，学习成本高，且对「临时接一台杂牌设备」不够友好。本项目只继承 HA 的三件核心能力，重做界面与接入路径：

| 从 HA 继承 | 具体落地 | 刻意不做 |
| --- | --- | --- |
| 设备抽象（entity + state + attribute） | 能力注册表（capabilities）+ 每设备状态对象 | 不做 entity registry / 区域层级 |
| 集成（integration） | 内置模板 + HTTP 适配器 + JSON 插件 | 不做本地协议发现（mDNS/CoAP/Zigbee） |
| 自动化（automation） | 定时任务（interval / daily / 5 段 cron） | 不做条件触发、模板引擎、场景脚本 |
| 前端面板 | 左右布局单页应用，黑白设计系统 | 不做主题市场、不做多租户 SaaS |

目标不是复刻 HA，而是给出一个**可运行、可测试、能自己扩展**的家庭面板参考实现。

---

## 2. 目标与非目标

### 2.1 目标（必须达成）

1. **能接管大多数设备**：灯光、开关、插座、温控、风扇、窗帘、门锁、传感器、空气质量、门窗磁、人体感应、摄像头、音箱，共 13 类内置模板 + 自定义设备。
2. **自定义接口请求**：任意设备可绑定 HTTP 接口，支持 URL/headers/body 模板渲染、动作写回、状态回读、超时与离线标记。
3. **多状态设备**：一台设备可同时声明多个能力（如灯光 = 开关 + 亮度 + 色温），状态写入受类型与范围校验。
4. **定时任务**：固定间隔、每天定点、5 段 cron 三种计划，可启停、立即执行、查看下次执行时间。
5. **完整 API 增删查改**：设备、分类、任务、令牌、插件、配对、导入导出全部有 REST 接口。
6. **AI 操作手册 + OpenAI 风格令牌**：面板内可下载给 AI Agent 的接口手册；提供 `/v1/chat/completions` 兼容端点，用 `sk-ice-…` Bearer 令牌调用。
7. **黑白简约 + 左右布局**：左侧是设备分类卡片与设置/配对/系统状态卡片，右侧是工作区；手机端侧栏收纳为抽屉。
8. **扫码导入 + 插件**：生成配对二维码、导出整份设备清单二维码、JSON 清单安装插件。
9. **账户与多账户 + 设备授权**：用户名口令登录，管理员/成员两种角色；成员只能看到并控制被授予的设备；支持按账户启停、改口令、调整授权。
10. **家居平面图**：SVG 画布绘制房间、拖放设备标记；框选一批设备后授给成员，或在清单中手动勾选。
11. **二维码配置与巡检**：配置二维码指向 10 分钟只读下载链接，设备标签二维码可扫码登记巡检；Wi-Fi 标准二维码联动受控私网网段扫描。
12. **无 emoji**：所有图标为自绘 24×24 SVG。
13. **测试闭环**：单元 + 集成 + E2E 三层测试全部可一键运行。
14. **Electron 桌面端**：本地内嵌服务 / 远程连接双模式；Windows/macOS/Linux x64+arm64；启动器、系统菜单与托盘；本地监听可让手机访问；同一数据目录加写入锁。

### 2.2 非目标（明确排除）

- 不做真实设备协议驱动（Zigbee/Z-Wave/MQTT 发现），HTTP 适配器即最小可用集成面。
- 不做用户自助注册、OAuth、多租户；账户由管理员在面板内创建与分配。
- 不做云同步、远程穿透；默认只在本机/局域网运行。
- 不做移动端原生 App；响应式 Web 覆盖手机与电脑。
- 不做依赖外部大模型的对话；内置确定性中文指令解析，保证离线可用与可测试。

## 3. 用户与使用场景

| 角色 | 场景 | 关键诉求 |
| --- | --- | --- |
| 家庭主理人 | 日常开关灯、看温湿度、设夜间关灯 | 一眼看懂、少点击、手机可用 |
| 家庭成员 | 只操作自己房间的设备 | 账户登录、只看到被授权设备、权限边界清晰 |
| 折腾型玩家 | 把自制 ESP32 灯带接进来 | 能填 URL/body 模板，能探测接口 |
| 自动化开发者 | 写脚本批量读状态、跑任务 | 稳定 REST + Bearer 令牌 + scope |
| AI Agent | 让模型读手册后直接控制家里 | 手册结构化、端点 OpenAI 兼容 |

典型任务流：

1. **接入**：新建分类 → 添加设备（选模板/自定义能力）→ 填 HTTP 接口 → 探测 → 保存。
2. **日常**：总览看 KPI 与设备卡 → 点卡片开抽屉调亮度/色温 → 或直接点卡片开关。
3. **自动化**：新建任务（每天 22:30 关灯）→ 到点执行 → 系统页看事件。
4. **对外**：签发 `device:write` 令牌 → 脚本用 `curl` 调 `/api/devices/:id/actions`。
5. **换机/交付**：导出设备清单二维码 → 另一套面板扫码导入。

## 6. 领域模型

### 6.1 实体

| 实体 | 关键字段 | 说明 |
| --- | --- | --- |
| `settings` | `homeName`、`allowLocalBootstrap`、`cache{}`、`wifi{ssid,password,security,hidden}` | 家庭名、缓存与 Wi-Fi 二维码参数；成员快照隐藏口令 |
| `categories[]` | `id`、`name`、`icon`、`order`、`description` | 左侧分类卡片来源，可无限新增 |
| `devices[]` | `id`、`name`、`template`、`capabilities[]`、`state{}`、`adapter{}`、`categoryId`、`online`、`pinned` | 一台设备 = 能力集合 + 状态快照 + 适配器 |
| `tasks[]` | `deviceId`、`schedule{}`、`action{}`、`enabled`、`nextRunAt`、`runCount` | 调度器每 15s 扫描 |
| `tokens[]` | `key`（哈希存储）、`prefix`、`scopes[]`、`userId`、`revoked`、`requestCount` | OpenAI 风格 Bearer；账户登录令牌带 `userId` |
| `users[]` | `id`、`username`、`displayName`、`role`、`deviceIds[]`、`passwordHash`、`active`、`lastLoginAt` | 管理员 / 成员；口令 `scrypt:salt:hash` |
| `plans[]` | `id`、`name`、`width`、`height`、`rooms[]`、`markers[]` | 房间矩形与设备坐标，标记按授权过滤 |
| `plugins[]` | `name`、`templates[]`、`hooks[]`、`enabled` | 贡献设备模板 |
| `pairings[]` | `code`、`deviceName`、`template`、`status` | 6 位配对码，排除易混字符 |
| `inspections[]` | `deviceId`、`deviceName`、`status`、`note`、`by`、`ts` | 扫码/手工巡检记录，最多保留 200 条，成员按设备授权过滤 |
| `events[]` | `level`、`category`、`message`、`ts` | 环形日志，系统页可筛选 |

### 6.2 能力（状态字段）注册表

`power`、`brightness`、`colorTemp`、`temperature`、`targetTemp`、`humidity`、`battery`、`position`、`volume`、`powerW`、`energyKwh`、`motion`、`contact`、`locked`、`illuminance`、`co2`、`pm25`、`speed`。

每个能力声明 `type`（enum / number / boolean）、`min/max`、`unit`、`default`。状态写入统一走 `normalizeValue`，越界或类型不符直接 400，避免脏状态进入存储。

### 6.3 设备模板

`light / switch / plug / climate / fan / cover / lock / sensor / air / contact / motion / camera / speaker / custom`。模板只决定**默认能力与图标**，用户可覆盖能力集合；插件可再贡献模板（如「阅读灯」）。

### 6.4 令牌与 scope

`device:read` → 读设备；`device:write` → 动作与增删改；`ai:use` → 自然语言与 OpenAI 端点；`admin` → 令牌/插件/配对/导入导出/账户/平面图/配置与 Wi-Fi 二维码/网段扫描。等级为 `admin ⊃ device:write ⊃ device:read`，`ai:use` 独立但被 admin 包含。密钥格式 `sk-ice-` + 32 位小写字母数字，仅在签发时返回一次，列表只给掩码。

账户角色映射：`admin` → `['admin']`，`member` → `['device:read','device:write','ai:use']`。scope 只决定能力类别，具体设备再由 `users[].deviceIds` 过滤：成员访问未授权设备返回 403 `device_forbidden`，`/api/state` 只下发授权设备及其任务/事件/平面标记。管理员不受 `deviceIds` 限制；管理员降级后，旧登录令牌按**当前角色**重新计算 scope，不保留 admin。

### 7.1 关键决策

| 决策 | 理由 | 代价 |
| --- | --- | --- |
| 单一根 `package.json`，不用 workspace | 一个人能跑起来优先于仓库洁癖 | 前后端依赖混在一起 |
| JSON 文件存储 + 原子写 | 零原生依赖，拷贝即备份，便于测试注入 | 不适合并发高写入（家庭场景够用） |
| 自写 cron 解析 | 5 段需求简单，避免引入依赖；可精确单测 | 不支持秒级与 `@yearly` 语法 |
| 确定性中文解析（不调模型） | 离线可用、结果可测、零成本 | 语义覆盖有限，复杂句会落到候选提示 |
| HTTP 适配器模板字符串 | 覆盖大多数 DIY 设备 | 不支持 OAuth 签名、WebSocket |
| 二维码导出裁剪字段 | QR 容量有限（完整 bundle 会溢出） | 导出不含 adapter 与插件 |
| 本机 loopback 自动签发 admin | 首次打开零摩擦 | 需提供开关关闭该行为 |
| 持久化适配器 + 整份文档存储 | 不重写业务访问层，JSON/SQL 共用同一套 store；测试零改动 | SQL 侧未拆表，无法按设备做 SQL 查询 |
| 驱动按需动态 import | 未装数据库驱动时仍可用 JSON，报错信息明确 | 首次连接有一次模块加载成本 |
| 缓存默认关闭 | 不改变「写完立即读到」的既有语义，升级零回归 | 需要用户主动到设置页开启 |
| 缓存键含令牌 ID、写后全量清空 | 简单、避免越权与陈旧数据 | 多实例需共享 Redis 才一致 |
| 前后端分离用环境变量而非新框架 | 单进程与分离部署同一份代码 | 跨域需显式配置来源 |
| 桌面端在主进程内跑 runtime | 不依赖系统 Node、不额外 spawn、打包即用 | 服务端 CPU 密集逻辑会占用主进程 |
| 桌面端 `asar=false` | 打包后 runtime 能按普通路径解析 `node_modules` 与 `dist` | 资源目录明文可见 |
| 数据目录 `.icehome.lock` | CLI 与桌面端不会并发写同一份 `db.json` | 异常退出可能留下锁，需按 PID 判活清理 |
| 远程页面不注入 preload | 远程内容不能调用桌面 IPC | 桌面端无法在远程页内做快捷操作，需走菜单/托盘 |
| 自签名证书按 host 放行 | 兼容家用 NAS 自签 HTTPS | 用户需明确勾选，仍有中间人风险 |

### 7.2 接口面（摘要）

- 认证：`POST /api/auth/bootstrap`（仅 loopback）、`POST /api/auth/login`（公开）、`GET /api/auth/me`、`POST /api/auth/logout`、`GET /api/health`（公开）
- 账户：`GET/POST /api/users`、`PATCH/DELETE /api/users/:id`、`POST /api/users/:id/grants`

- 基础设施：`GET /api/cache/stats`、`POST /api/cache/purge`、`POST /api/system/storage/test`
- 设备：`GET/POST /api/devices`、`GET/PATCH/DELETE /api/devices/:id`、`POST /api/devices/:id/actions`、`POST /api/devices/:id/probe`
- 分类：`GET/POST /api/categories`、`PATCH/DELETE /api/categories/:id`
- 任务：`GET/POST /api/tasks`、`PATCH/DELETE /api/tasks/:id`、`POST /api/tasks/:id/run`
- 令牌：`GET/POST /api/tokens`、`PATCH/DELETE /api/tokens/:id`
- 插件：`GET/POST /api/plugins`、`PATCH/DELETE /api/plugins/:id`

错误统一为 `{ error: { code, message } }`，`code ∈ validation_error | unauthorized | invalid_token | forbidden | not_found | conflict | internal_error`。

## 9. 风险与对策

| 风险 | 影响 | 对策（已落地） |
| --- | --- | --- |
| 二维码容量溢出 | 导出/配对 400 | 设备清单裁剪；完整配置二维码只编码 10 分钟有效的下载短链；QR 纠错 M→L 降级 |
| 配置短链泄露 | 家庭配置与 Wi-Fi 口令被下载 | 仅 admin 生成、32 字节随机 token、10 分钟过期、只读 JSON；界面提示可信环境展示 |
| 网段扫描被滥用 | 扫描非家庭网络 | 只允许 RFC1918/loopback、`/24-/32`、最多 254 主机、8 端口、超时/并发受限；仅 admin；HTTP/TLS/RTSP/MQTT 做协议级校验，未知端口回退 TCP |
| 裸 TCP 误报 | 网络中间层接受所有连接，扫描列出不存在主机 | 常见端口不再只看 connect，HTTP 需响应状态、TLS 需完成握手、RTSP/MQTT 需返回协议报文；未知端口在界面标注为 tcp |
| 巡检记录越权 | 成员看到未授权设备巡检 | 记录按 `deviceIds` 过滤；巡检事件纳入 `visibleEvents` 的 meta 裁剪 |
| 摄像头不可用 | 无法扫码 | 保留手工粘贴标签内容路径；提示 BarcodeDetector 兼容性 |
| 插件模板能力丢失 | 插件设备退化为单开关 | `buildDevice` 接收 `templates`，优先匹配插件模板 |
| 能力变更后残留旧状态 | 状态字段非法 | 改能力时用 `normalizeState` 重算 |
| cron 表达式非法 | 任务静默不执行 | 创建时解析校验，非法直接 400 |
| 令牌泄露 | 全屋被控 | 掩码展示、吊销即时生效、不得删除当前令牌 |
| 无真实设备也能演示 | 体验空白 | seed 10 台演示设备 + mock 适配器 + HTTP 探测 |
| 移动端侧栏遮挡 | 手机上无法操作 | 抽屉式导航 + 遮罩 + 关闭按钮，E2E 覆盖 |
| 桌面端重复写数据 | CLI 与 Electron 同时打开同一 `data` 导致覆盖 | `.icehome.lock` 记录 PID，活进程占用时第二个实例直接拒绝启动 |
| 远程页面获得桌面能力 | 恶意远程面板调用本地 IPC | 面板窗口不加载 preload；启动器才有限 IPC；远程导航锁 origin |
| 自签名证书被滥用 | 中间人攻击 | 默认走 Chromium 校验；仅显式勾选且 hostname 匹配时放行 |
| Electron 打包路径失效 | 安装后找不到 dist/server | `asar=false`，runtime 使用 `app.getAppPath()`，打包后 E2E 可验 |
| 多架构构建失败 | arm64 无产物 | CI 分架构矩阵；纯 JS 依赖不重编；失败任务独立不拖垮其他平台 |
| 数据库不可用 | 服务无法启动 | 启动即校验连接并给出中文错误；可回退 JSON，界面展示连接状态 |
| Redis 不可用 | 缓存功能失效 | 自动降级内存并记录 `fallbackReason`，服务不中断 |
| 缓存导致读到旧数据 | 状态不同步 | 默认关闭；写请求后全量失效；`no-cache` 可强制回源 |
| 跨域配置错误 | 前后端分离后 401/404 | `CORS_ORIGINS` 显式来源 + 网关统一代理 `/api` `/v1` |
| 账户越权 | 成员看到/控制别人设备 | 角色 scope + `deviceIds` 二次过滤；未授权 403；状态快照裁剪 |
| 管理员降级后旧令牌越权 | 旧会话仍是 admin | scope 按账户当前角色实时计算，不缓存角色 |
| 成员误删平面/账户 | 数据被破坏 | 账户与平面图写接口仅 admin，前端侧栏按角色隐藏入口 |
